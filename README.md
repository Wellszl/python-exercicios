# python-exercicios

Exercícios de Python para revisão: fundamentos, NumPy, Matplotlib e pandas.

## Estrutura

- `fundamentos/` — exercícios de lógica e conceitos básicos de Python.
- `requirements.txt` — dependências usadas nos exercícios (numpy, pandas, matplotlib).
- `.gitignore` — ignora caches, ambientes virtuais e arquivos de IDE.

## Como usar

1. Crie e ative um ambiente virtual:
   ```bash
   python -m venv .venv
   ```
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
